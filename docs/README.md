## Machine Learning

- [Logistic regression (L2)](machine-learning/model.md) - `baseline` Sanity check and reference point 
- [Logistic regression (elastic net / L1)](machine-learning/model.md) - Built-in feature selection, interpretable 
coefficients,and usually very strong on RNA-seq
- [Linear SVM](machine-learning/model.md) - A classic for expression data; works well when p >> n
- [Random forest](machine-learning/model.md) - Non-linear, robust, gives importance scores
- [Gradient boosting (XGBoost or LightGBM)](machine-learning/model.md) - Usually the best tabular non-linear model
